# Keyboard shortcuts

The keys act on the highlighted row. The first arrow press puts the highlight on the first row rather than jumping blindly.

## In the list

| Keys | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>PageUp</kbd> <kbd>PageDown</kbd> <kbd>Home</kbd> <kbd>End</kbd> | Move through the list |
| <kbd>Enter</kbd> | Go into the folder, or open the file |
| <kbd>Backspace</kbd> | Up one level |
| <kbd>Space</kbd> | Tick or untick the row |
| <kbd>Shift+↑</kbd> <kbd>Shift+↓</kbd> | Tick a run of rows on the way |
| <kbd>a…z</kbd> | Jump to the next row starting with those letters, wrapping round |
| <kbd>Ctrl+A</kbd> | Tick everything, or untick it if it is all ticked |
| <kbd>Alt+←</kbd> <kbd>Alt+→</kbd> | Back and forward |
| <kbd>Ctrl+O</kbd> <kbd>Ctrl+N</kbd> <kbd>Ctrl+E</kbd> | Open · new archive · extract it all |
| <kbd>Ctrl+C</kbd> | Copy the selected names |
| <kbd>Ctrl+F</kbd> <kbd>F5</kbd> | Jump to the filter box · read the archive again |
| <kbd>Delete</kbd> | Take the selected entries out of the archive |
| <kbd>Esc</kbd> | Back out of whatever is on top |

> [!NOTE]
> **When typing**
>
> While the filter box or a dialog has the keyboard, none of these apply, and the keys go to that box or dialog.

## With the mouse

- Click for one entry, Ctrl+click to add or drop one, Shift+click for everything in between.
- Press and drag on the list for a rubber-band rectangle.
- The mouse’s back and forward buttons move through history.
