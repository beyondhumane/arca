# Roadmap

What Arca doesn’t do yet and, where it matters, why.

## Not yet

- **The 7z format.**
- **xz / LZMA2.**
- **Symbolic links:** skipped when creating today.
- **GNU tar long names.**
- **Solid archives:** compressing every file as one stream, which is where the largest ratio gain comes from.
- **Desktop integration on Linux and macOS:** the Explorer menu is Windows-only for now.
- **Adding to an existing archive:** the prerequisite for <kbd>Ctrl+V</kbd> in the window.
- **A native format:** at which point Zstandard becomes the default codec.
