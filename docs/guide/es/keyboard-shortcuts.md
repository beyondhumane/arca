# Atajos de teclado

Las órdenes de lista actúan sobre el panel activo. Los campos de texto y los diálogos conservan sus teclas de edición.

| Teclas | Acción |
| --- | --- |
| <kbd>Arriba</kbd> <kbd>Abajo</kbd> <kbd>RePág</kbd> <kbd>AvPág</kbd> <kbd>Inicio</kbd> <kbd>Fin</kbd> | Mover el cursor |
| <kbd>Derecha</kbd> | Entrar en la carpeta del cursor |
| <kbd>Izquierda</kbd> <kbd>Retroceso</kbd> | Subir a la carpeta superior |
| <kbd>Intro</kbd> | Entrar en una carpeta o abrir explícitamente un archivo con la aplicación del sistema |
| <kbd>Espacio</kbd> | Alternar la selección de la fila del cursor |
| <kbd>Mayús+Arriba</kbd> <kbd>Mayús+Abajo</kbd> | Ampliar la selección |
| <kbd>Ctrl+A</kbd> | Seleccionar filas visibles del panel activo |
| <kbd>a…z</kbd> | Saltar por prefijo del nombre |
| <kbd>Alt+Izquierda</kbd> <kbd>Alt+Derecha</kbd> | Atrás y adelante en el historial |
| <kbd>Ctrl+O</kbd> <kbd>Ctrl+N</kbd> <kbd>Ctrl+E</kbd> | Abrir archivo, crear archivo, extraer todo |
| <kbd>Ctrl+C</kbd> <kbd>Ctrl+X</kbd> <kbd>Ctrl+V</kbd> | Copiar, cortar y pegar archivos (integración con Windows) |
| <kbd>Ctrl+Mayús+C</kbd> | Copiar los nombres seleccionados como texto |
| <kbd>Ctrl+F</kbd> | Mostrar y enfocar el filtro del panel activo |
| <kbd>F2</kbd> | Renombrar la entrada seleccionada en un ZIP modificable |
| <kbd>F3</kbd> | Activar la vista previa integrada del archivo del cursor |
| <kbd>Ctrl+T</kbd> | Comprobar el archivo |
| <kbd>Ctrl+I</kbd> | Invertir la selección visible del panel activo |
| <kbd>F5</kbd> | Volver a leer el archivo |
| <kbd>Supr</kbd> | Confirmar la eliminación de entradas seleccionadas de un ZIP modificable |
| <kbd>Ctrl+Z</kbd> | Deshacer la última modificación compatible |
| <kbd>Alt+W</kbd> | Extraer aquí |
| <kbd>+</kbd> <kbd>-</kbd> | Seleccionar o deseleccionar por máscara de nombre |
| <kbd>Tab</kbd> <kbd>Mayús+Tab</kbd> | Mover el foco entre controles y paneles |
| <kbd>F1</kbd> | Ayuda de atajos |
| <kbd>Esc</kbd> | Cerrar el diálogo o la edición en línea; en otro caso, quitar la selección |

Ctrl+clic alterna una fila; Mayús+clic selecciona un intervalo. Un clic en una carpeta abre su hijo en Columnas; Detalles usa doble clic. Haz clic derecho en una fila o espacio vacío del panel para abrir su menú. Arrastra los divisores para ajustar el ancho y desplázate horizontalmente para llegar a los antecesores.

El botón de cierre de vista previa devuelve el foco. En ventanas estrechas puede quedar suspendida temporalmente hasta que haya sitio. El botón lateral alterna entre panel ampliado, iconos y oculto.

Atajos de aplicación como Ctrl+O siguen disponibles desde campos de texto; la navegación normal, Espacio, Supr y F3 no sustituyen a la edición.
