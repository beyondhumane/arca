# Atajos de teclado

Las teclas actúan sobre la fila resaltada. La primera pulsación de flecha pone el resaltado en la primera fila en lugar de saltar a ciegas.

## En la lista

| Teclas | Acción |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>PageUp</kbd> <kbd>PageDown</kbd> <kbd>Home</kbd> <kbd>End</kbd> | Desplazarse por la lista |
| <kbd>Enter</kbd> | Entrar en la carpeta, o abrir el archivo |
| <kbd>Backspace</kbd> | Subir un nivel |
| <kbd>Space</kbd> | Marcar o desmarcar la fila |
| <kbd>Shift+↑</kbd> <kbd>Shift+↓</kbd> | Marcar una serie de filas por el camino |
| <kbd>a…z</kbd> | Saltar a la siguiente fila que empiece por esas letras, dando la vuelta |
| <kbd>Ctrl+A</kbd> | Marcar todo, o desmarcarlo si ya está todo marcado |
| <kbd>Alt+←</kbd> <kbd>Alt+→</kbd> | Atrás y adelante |
| <kbd>Ctrl+O</kbd> <kbd>Ctrl+N</kbd> <kbd>Ctrl+E</kbd> | Abrir · nuevo archivo · extraerlo todo |
| <kbd>Ctrl+C</kbd> | Copiar los nombres seleccionados |
| <kbd>Ctrl+F</kbd> <kbd>F5</kbd> | Saltar al cuadro de filtro · volver a leer el archivo |
| <kbd>Delete</kbd> | Sacar las entradas seleccionadas del archivo |
| <kbd>Esc</kbd> | Salir de lo que esté encima |

> [!NOTE]
> **Al escribir**
>
> Mientras el cuadro de filtro o un diálogo tenga el foco del teclado, ninguna de estas se aplica, y las teclas van a ese cuadro o diálogo.

## Con el ratón

- Clic para una entrada, Ctrl+clic para añadir o quitar una, Shift+clic para todo lo que hay en medio.
- Pulsa y arrastra sobre la lista para un rectángulo de selección.
- Los botones de atrás y adelante del ratón se mueven por el historial.
